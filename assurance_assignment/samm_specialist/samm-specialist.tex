\sectionheading{1. Core}
\subheading{Security Testing (Verification)}
Dedicated security test cases for known-risk areas, run regularly.
Audit: authorization, path traversal, login throttling and link access.
Existing link tests checked HTTP 200/PDF without authentication for an issued
link; HTTP 404/no PDF for random, last-character-flipped, plus-one and all-zero
unissued links; and separation of two users' documents and watermark secrets.
Pytest runs in CI on PRs to \texttt{main} and pushes to \texttt{main}/\texttt{feat/**}.

The manual SHA-1(\texttt{s1}) check became an automated regression:
\par\texttt{GET /api/get-version/640d87e741e6aa4c669a82a4cd304787960513ab}\par
Result: HTTP 404, no PDF. Four negative-link cases gained assertions excluding
both users' secrets, recipients and filenames from responses. On 30 September,
the focused module passed all seven cases and Ruff. Commit:
\href{https://github.com/chirichexe/tatou-2026/commit/fbae18a9970c721a8809d2ff2d43ef10be03d7fc}{\texttt{fbae18a}}.
